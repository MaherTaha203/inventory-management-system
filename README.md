# نظام الجرد والاستلام

تطبيق ويب عربي بواجهة RTL لتسجيل عمليات الجرد وسندات استلام البضائع بصورة مستقلة. النظام دفتر إلكتروني للتسجيل والمتابعة، ولا يحسب أرصدة أو كميات شراء أو أسعار.

## الحالة الحالية

- فرع العمل: `develop`.
- قاعدة البيانات: مشروع Supabase الحالي، وقد طُبقت عليه 15 ترحيلاً جديداً.
- الواجهة: الجرد، الاستلام، القوائم، الأرشيف، التقارير، سجل الصنف، سلة المحذوفات، والإعدادات.
- المسودات: IndexedDB محلياً لكل جهاز.
- الدخول: رمز مشترك من ستة أرقام وجلسات أجهزة.
- الاستيراد: ملفات Excel بصيغتي XLS وXLSX.
- التصدير: XLSX، والطباعة أو الحفظ PDF من نافذة الطباعة.
- النشر: لم يتم النشر إلى Vercel بعد.

## المتطلبات

- Node.js 22 أو أحدث.
- npm.

## التشغيل المحلي

1. انسخ ملف البيئة:

   ```bash
   cp .env.example .env.local
   ```

2. أضف القيم المطلوبة إلى `.env.local`:

   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
   - `SUPABASE_SECRET_KEY` (سري، للخادم فقط)
   - `INITIAL_SETUP_SECRET` (سر عشوائي بطول 32 حرفاً على الأقل)
   - `CRON_SECRET` (سر عشوائي بطول 32 حرفاً على الأقل)

3. ثبّت الحزم وشغّل التطبيق:

   ```bash
   npm install
   npm run dev
   ```

4. افتح `http://localhost:3000`. عند أول تشغيل، أدخل رمز الدخول المشترك ومفتاح التهيئة.

لا تضع المفاتيح السرية في Git، ولا تستخدم `SUPABASE_SECRET_KEY` في المتصفح.

## قاعدة البيانات

تفاصيل بنية قاعدة البيانات، ترتيب الترحيلات، الصلاحيات، التحقق، ومتغيرات البيئة موثقة في [supabase/README.md](supabase/README.md).

## البنية

```text
src/
  app/                 صفحات النظام وواجهات API
  features/
    auth/              بوابة الدخول والجلسات
    catalog/           الأصناف والموردون والوحدات
    operations/        الجرد والاستلام والمسودات والاستيراد
  lib/
    auth/              التحقق من رمز الدخول والجلسات
    local-drafts/      IndexedDB
    realtime/          إشعارات التحديث بين الأجهزة
    supabase/          عملاء قاعدة البيانات
    validation/        التحقق من الأسماء والكميات والتواريخ
  types/               الأنواع المشتركة
supabase/
  migrations/          ترحيلات قاعدة البيانات
```

## ما قبل التشغيل الفعلي

يلزم إدخال أسرار البيئة محلياً أو في منصة النشر، وإجراء اختبار تكاملي للدخول والجلسات والتحديث الآني، وتجربة ملفات استيراد فعلية، والتحقق من مهمة Vercel Cron بعد ضبط `CRON_SECRET`.
